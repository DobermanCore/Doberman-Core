- **Cursor runs the Claude Code hooks too, and `doberman hook pre` now answers them (#576).** Cursor's
  third-party-hooks setting loads the hooks from the Claude settings files and invokes them with a Cursor-shaped
  payload (`cwd: ""`, the project only in `workspace_roots`, the shell tool named `Shell`), which `hook pre`
  used to fail closed on, so every Cursor shell command was denied on a machine with `install-hooks --global`.
  `hook pre` recognises that shape and routes it through the Cursor adapter (a deny becomes the usual
  `hookSpecificOutput` block, an allow abstains); the adapter's single-flight now spans hook sources, so the
  native `preToolUse` / `beforeShellExecution` pair and the compat path share one evaluation and one dialog per
  action, with approvals still single-use. Real captured cursor-agent payloads (BOM included, identifying fields
  scrubbed) replace the doc-derived fixtures. Refs #202.
