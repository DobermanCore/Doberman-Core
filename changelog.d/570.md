- **Reverse/bind shells now hard-block instead of prompting.** A network channel wired to command execution — `nc -e`/`--sh-exec`, socat `EXEC:`/`SYSTEM:`, and a `python -c`/`node -e` payload that opens a socket *and* spawns a subprocess/shell — is a `BLOCK` (`raw_socket_channel`), not an approvable `AUTH`. Every other raw-socket shape (a bare `/dev/tcp` redirect, a `nc -zv` probe, `openssl s_client`, a bare inline socket) is unchanged. Raise-only. (ADR 0097)
