- **Dashboard control-surface pass.** The mode form now actually closes (a
  missing `[hidden]` rule kept it permanently open), states the raise-only rule
  up front, and confirms a save inline before closing. Approve/deny failures,
  a dropped live feed, and a failed refresh are all now visible in the UI
  instead of failing silently, with retry controls where that matters. Pending
  cards show a live countdown to the dashboard's real 90s answer window
  (`auto-denies in M:SS if unanswered`) instead of the DB row's unrelated 120s
  TTL, Deny is now the solid/primary action (Approve stays outlined, two-step
  armed, with a visible 3s countdown), and the TOTP field gets a real
  `<label>`. Verdict filter chips plus a text filter sit above the recent-
  decisions feed so a BLOCK is easy to find, and `top_reason_codes`/
  `recent_verdict_counts` (already computed server-side) are finally rendered.
  New keyboard shortcuts (`/` filter, `Esc` clears it, arrow keys/Home/End move
  the active feed row, Enter/Space expands its explanation, `r` refresh, `a`/`d`
  act on the first pending item, `?` shortcuts panel) are documented in that
  panel. Landmarks, authored `:focus-visible`, 44px hit targets, a four-step
  type scale, and a mobile breakpoint round out the accessibility and
  responsive floor; a manual light/dark toggle persists per browser, and the
  browser tab favicon tints amber while an approval is pending.
- **Round-3 control-surface pass.** The pending countdown now states what
  actually happens at 0 (the challenge moves to the terminal/GUI channel, it
  is never silently denied). Every BLOCK/AUTH row in the recent-decisions feed
  now carries the same one-line human explanation the pending cards already
  had, with reason codes individually glossed via a hover tooltip; feed rows
  are keyboard-navigable (roving focus, `aria-activedescendant`) and their
  explanation expands with Enter/Space. Component boundaries (rules, card
  surfaces) now clear WCAG 1.4.11 in both themes, and every button label
  clears 4.5:1 text contrast. The mode-change form is now an anchored popover
  under its trigger at wider widths, its options are labeled by strictness,
  and a live hint explains whether the current selection raises (immediate)
  or lowers (needs a code) strictness. The topbar groups into status/posture/
  utility clusters, the decisions filter is no longer a keyboard trap, the
  stats line shows a last-updated time, and the shortcuts panel's title no
  longer pollutes the page's heading outline.
- **Round-4 control-surface pass.** Feed rows now expand by click/tap as well
  as Enter/Space (`cursor: pointer`, `aria-expanded`), and the explanation is
  the row's primary text (full-contrast body face) with reason codes demoted
  to a secondary muted mono line — the same hierarchy on pending cards. Every
  glossed reason code gets a small `?` next to its hover tooltip that toggles
  the identical gloss as plain text, so keyboard and touch users reach it too.
  Roving focus in the decisions feed now moves real DOM focus (`tabindex`)
  instead of `aria-activedescendant`, and each row carries a full accessible
  name. Lowering the strictness mode is now gated at least as hard as an
  approval: Save restyles to the BLOCK color and needs the same arm-then-
  confirm gesture (5s countdown) before it submits; raising stays one click.
  `REASON_DESCRIPTIONS` now covers all 58 `ReasonCode` values (was 36).
  Verdict filter chips color by the verdict they filter to (BLOCK/AUTH/PASS),
  and Deny's solid fill moved to neutral tan — BLOCK red is reserved for
  verdict/risk badges and the downgrade Save. At narrow widths the decisions
  filter no longer stretches to fill the column, the mode/enforcement badges
  no longer wrap their text onto two lines, and Clear Filters reaches the
  44px hit-target floor. The mode-change popover is a light-dismiss dialog
  (an outside click closes it unless a change is pending) with Tab focus
  containment, and a single Escape now closes only the topmost open thing
  (popover, then shortcuts panel, then the filter) instead of all of them at
  once; the shortcuts panel itself now anchors under its own trigger instead
  of the viewport corner. Feed rows no longer show "from:unknown" noise when
  the origin is genuinely unknown, and dark-theme muted text clears 4.5:1
  contrast against a hovered row (was 4.48:1).
